# คู่มือติดตั้ง — ระบบนิเทศฝึกสอน (Google Apps Script)

ระบบนี้รันบน **Google Apps Script** ใช้ **Google Sheets เป็นฐานข้อมูล** และล็อกอินด้วย **บัญชี Google ของมหาวิทยาลัย** (โดเมน `@…kmutnb.ac.th`)

ไฟล์ในโฟลเดอร์นี้:
| ไฟล์ | หน้าที่ |
|------|--------|
| `Code.gs` | Backend — อ่าน/เขียน Sheets, state machine, RBAC, audit log |
| `Setup.gs` | สร้างตาราง + ใส่ข้อมูลตัวอย่าง (รันครั้งเดียว) |
| `Index.html` | หน้าเว็บทั้งหมด (UI ธีมส้มนีออน) |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (สิทธิ์, การเข้าถึง) |

---

## วิธีติดตั้ง (แบบง่าย — ไม่ต้องใช้เครื่องมือเพิ่ม)

### 1) สร้าง Google Sheet
- เข้า [sheets.new](https://sheets.new) ด้วยบัญชีมหาวิทยาลัย → ตั้งชื่อเช่น **"ฐานข้อมูลนิเทศฝึกสอน"**

### 2) เปิด Apps Script
- ในชีต: เมนู **ส่วนขยาย (Extensions) → Apps Script**
- จะได้โปรเจกต์สคริปต์ที่ผูกกับชีตนี้ (container-bound)

### 3) ใส่โค้ด
ในหน้าต่าง Apps Script:
- **`Code.gs`** — วางเนื้อหาจากไฟล์ `Code.gs`
- กด **＋ → Script** ตั้งชื่อ `Setup` แล้ววางเนื้อหา `Setup.gs`
- กด **＋ → HTML** ตั้งชื่อ `Index` (ต้องชื่อนี้เป๊ะ) แล้ววางเนื้อหา `Index.html`
- เปิด **⚙ Project Settings → ติ๊ก "Show appsscript.json"** แล้วไปที่ไฟล์ `appsscript.json` วางเนื้อหาทับ

### 4) รันตั้งค่าครั้งแรก
- เลือกฟังก์ชัน **`setupSpreadsheet`** ด้านบน → กด **Run**
- ครั้งแรกจะขออนุญาตสิทธิ์ → **Review permissions → เลือกบัญชี → Allow**
- กลับไปดูชีต จะมีแท็บ `Users`, `Enrollments`, `AuditLog` พร้อมข้อมูลตัวอย่าง

### 5) ตั้งผู้ใช้จริง (สำคัญ)
- เปิดแท็บ **`Users`** ในชีต → แก้อีเมลอย่างน้อย 1 แถวเป็น **อีเมลจริงของคุณ** และตั้ง role = `ADMIN`
- (คนอื่นเข้ามาครั้งแรกจะเจอหน้าลงทะเบียนให้กรอกเอง)

### 6) เผยแพร่เป็นเว็บแอป
- กด **Deploy → New deployment → ⚙ เลือก Web app**
- ตั้งค่า:
  - **Execute as:** `Me` (ตัวคุณ — เจ้าของชีต)
  - **Who has access:** `Anyone within [มหาวิทยาลัย]` (โดเมน kmutnb.ac.th)
- กด **Deploy** → คัดลอก **Web app URL** ไปใช้/แจกได้เลย

เปิด URL นั้น → ถ้าอีเมลคุณอยู่ใน `Users` แล้วจะเข้าแดชบอร์ดทันที; ถ้ายังไม่มีจะเจอหน้าลงทะเบียน

## ทางเลือกสำหรับนักพัฒนา (clasp)
ถ้าถนัด command line ใช้ [clasp](https://github.com/google/clasp) push ไฟล์ทั้งโฟลเดอร์ได้:
```bash
npm i -g @google/clasp
clasp login
clasp create --type sheets --title "ระบบนิเทศฝึกสอน"
clasp push        # ดันไฟล์ในโฟลเดอร์นี้ขึ้นไป
```

---

## ทดลองดูหน้าตาก่อน deploy
เปิดไฟล์ `Index.html` ในเบราว์เซอร์ธรรมดา (หรือ `python3 -m http.server` แล้วเปิด) — จะรัน **โหมดพรีวิว** ใช้ข้อมูลจำลอง มีตัวสลับบทบาทมุมซ้ายล่างให้ลองทุกมุมมอง (เจ้าหน้าที่ / อาจารย์ / นักศึกษา / ผู้ดูแล / หน้าลงทะเบียน) โดยไม่แตะฐานข้อมูลจริง

## หมายเหตุ / ก้าวต่อไป
- **ที่ทำงานแล้ว (รอบแรก):** ล็อกอิน+ลงทะเบียน, แดชบอร์ดตามสิทธิ์, หน้า detail + workflow tracker, เดินสถานะทั้ง flow บันทึกลง Sheets จริง, audit log
- **เฟสถัดไป:** อัปโหลดหลักฐานกิจกรรม (→ Google Drive), หน้ากรอกแบบประเมินจริง, บันทึกการลงพื้นที่นิเทศ, export ส่งคุรุสภา
- ข้อมูลทั้งหมดอยู่ในชีต เจ้าหน้าที่เปิดดู/แก้เองได้ และดาวน์โหลดเป็น Excel/PDF ได้ทันที
